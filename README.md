# Hajime OS

نظام خادم على FreeBSD 14.4 يحلّ محلّ مكدّس دوكر كان يشغّل سبع عشرة حاوية على
جهاز بثمانية جيجابايت. الأدوات مكتوبة بـ Rust، وكل واحدة تحلّ محلّ خدمة كانت
تُستهلك جاهزة.

## لماذا

المكدّس القديم كان يستهلك 6.9 جيجابايت من أصل 8، ويتبادل الذاكرة مع القرص،
وكل تحديث فيه مقامرة لأن لا طريق للرجوع. FreeBSD يعطي بيئات إقلاع ZFS: لقطة
قبل التغيير، وإن انكسر شيء تُقلع على الأمس فيرجع النظام كله لا ملف واحد.

## ما بداخله

| المجلد | ماذا يفعل |
|---|---|
| `hajime-core` | مكتبة مشتركة: مصادقة، سياسة، أسرار، سجل تنفيذ، بوابة أدوات، قفل |
| `hajime-workflow` | محرّك وركفلو يقرأ تصدير n8n نفسه، 11 نوع عقدة |
| `hajime-ai` | بوابة النموذج المحلي وأدواته |
| `hajime-wa` | بوابة واتساب فوق جسر Go |
| `hajime-social` | نشر على أربع منصات |
| `hajime-fetch` | جلب صفحات واستخلاص نصها، بديل متصفح كامل |
| `hajime-sys` | `hajimectl`: خدمات، لقطات، فحص إقلاع، وضع توفير، jails |
| `hajime-console` | صفحة واحدة تقول ما المكسور وما الذي عمل |
| `hajime-wm` | سطح مكتب wayfire وثيم بألوان الشعار |
| `hajime-jails` | ثلاثة jails وقواعد pf |
| `hajime-migrate` | نسخ احتياطي واستعادة من الخادم القديم |

## التثبيت

بالترتيب. كل خطوة تفترض أن التي قبلها نجحت.

```bash
sh install_hajime_os.sh --dry-run
```

جرّبها جافّة أولاً. تعرض الخطة كاملة ولا تغيّر شيئاً، وتقول في آخرها هل كان
التشغيل الحقيقي سيمضي أم سيتوقف.

```bash
sh install_hajime_os.sh
```

ينشئ بيئة إقلاع قبل أول تغيير، فالتراجع عن كل ما يلي هو `bectl activate`
وإعادة تشغيل.

```bash
sh hajime-migrate/restore_data.sh /vault/hajime_backups/<التاريخ>
```

يتحقق من `SHA256SUMS` قبل أن يكتب بايتاً واحدة، ويتوقف عند أول فشل لا يستطيع
شرحه، ويقول في آخره ما الذي لم يُستعَد.

```bash
hajimectl check
hajimectl start
```

سطح المكتب وjails اختياريان ومنفصلان:

```bash
sh hajime-wm/install_desktop.sh
sh hajime-jails/create_jails.sh
```

## الاستعمال اليومي

```bash
hajimectl status
hajimectl save
hajimectl snapshot before-upgrade
hajimectl jails
```

`save` يوقف الخدمات الاختيارية ويُبقي المواقع تعمل، للحظات ضيق الذاكرة.
`resume` يعيدها.

قبل تجربة وركفلو مستورد لأول مرة، شغّله في الظل:

```bash
curl -X POST 'http://127.0.0.1:5678/api/workflows/<id>/run?shadow=1'
```

الرسم يُمشى كاملاً، والقراءات تحدث فعلاً، لكن أي عقدة تغيّر شيئاً خارج العملية
تُحجَز وتُخرج وصفاً لما كان سيحدث. الوركفلوهات المستوردة تنشر على واتساب وأربعة
حسابات، فأول تشغيل لها بعد الترحيل يجب ألّا يكون الحقيقي.

## البناء

```bash
cargo build --release --workspace
cargo test --workspace
```

على FreeBSD يلزم `pkg install llvm19` لأن `rquickjs` لا يشحن ارتباطات جاهزة
لهذه المنصة فيولّدها بـ bindgen، وbindgen يحتاج libclang.

## الحالة

مُختبَر على FreeBSD 14.4 داخل جهاز افتراضي: 281 اختباراً، صفر فشل، وكل
السكربتات تُحلَّل بـ `sh` الخاص بـ FreeBSD. الخادم نفسه ما زال على Alpine
لأن التثبيت يحتاج وسائط وحضوراً: الجهاز بلا IPMI، وFreeBSD لا تُثبَّت عبر SSH.

التفاصيل في `STATUS.md`، والأسباب وراء كل قرار في `decisions.md`.
